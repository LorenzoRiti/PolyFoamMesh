PolyFoamMesh
============

Desktop standalone mesh generator for OpenFOAM using cfMesh/cartesianMesh.

For the user guide (installation, workflow, known limitations) see the
repository's `docs/INSTALL.md <https://github.com/LorenzoRiti/PolyFoamMesh/blob/main/docs/INSTALL.md>`_
and `docs/USER_GUIDE.md <https://github.com/LorenzoRiti/PolyFoamMesh/blob/main/docs/USER_GUIDE.md>`_.
This Sphinx site covers the API reference only.
