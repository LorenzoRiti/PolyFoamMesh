PolyFoamMesh
============

Desktop standalone mesh generator for OpenFOAM using cfMesh/cartesianMesh.

For the user guide (installation, workflow, known limitations) see the
repository's ``docs/INSTALL.md``, ``docs/INSTALL_LINUX.md`` and
``docs/USER_GUIDE.md``.
This Sphinx site covers the API reference only.
