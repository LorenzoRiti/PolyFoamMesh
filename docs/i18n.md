# Internationalization (i18n) Toolchain

PolyFoamMesh supports multiple languages via Qt Linguist `.ts` / `.qm` files.

## Toolchain

### 1. Extract translatable strings

```bash
pyside6-lupdate src/ -ts locale/it/LC_MESSAGES/polyfoammesh.ts
```

This scans all Python files in `src/` for `tr()` calls and generates/updates the `.ts` file.

### 2. Translate

Open the `.ts` file in Qt Linguist:

```bash
pyside6-linguist locale/it/LC_MESSAGES/polyfoammesh.ts
```

Translate each string and mark as "Done". Save.

### 3. Compile to `.qm`

```bash
pyside6-lrelease locale/it/LC_MESSAGES/polyfoammesh.ts
```

This generates `polyfoammesh.qm` in the same directory.

### 4. Fallback chain

The app loads translations in this order:

1. `locale/<lang>/LC_MESSAGES/` inside the project
2. Qt's own `TranslationsPath`

## Adding a new language

```bash
mkdir -p locale/fr/LC_MESSAGES/
cp locale/it/LC_MESSAGES/polyfoammesh.ts locale/fr/LC_MESSAGES/
# Translate in Qt Linguist
pyside6-lrelease locale/fr/LC_MESSAGES/polyfoammesh.ts
```

## Python-level setup

`app.py` calls `_init_i18n(app)` after `QApplication(sys.argv)`. The `_init_i18n` function walks the fallback path list and installs the first `QTranslator` that loads successfully.
